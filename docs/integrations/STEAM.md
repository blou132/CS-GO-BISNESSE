# Steam Community Market

- Statut : `RESEARCH_REQUIRED`
- Marché officiel : <https://steamcommunity.com/market/>
- Documentation Steamworks : <https://partner.steamgames.com/doc/webapi_overview>
- Vérification : 8 septembre 2026

La documentation Steamworks décrit la Web API générale mais pas une API
publique officielle destinée à collecter les listings et ventes du Community
Market. Les URLs utilisées par le site ne sont pas considérées comme un contrat
développeur. Aucun scraping ou contournement n'est mis en place.
