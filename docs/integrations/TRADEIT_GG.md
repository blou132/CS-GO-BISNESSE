# Tradeit.gg

- Statut : `RESEARCH_REQUIRED`
- Site officiel : <https://tradeit.gg/>
- Centre d'aide officiel : <https://support.tradeit.gg/en/>
- Vérification : 8 septembre 2026

Tradeit.gg est la plateforme CS2 étudiée. `tradeit.app` est un produit financier
sans rapport et ne constitue jamais une source pour ce projet.

Aucune documentation officielle d'API développeur publique fournissant
inventaire, trade-in, trade-out ou quote read-only n'a été identifiée sur le
site et le centre d'aide officiels. Cela ne nie pas l'existence éventuelle d'une
API partenaire : une autorisation et un contrat officiels seraient requis avant
toute intégration. Aucun endpoint privé n'est rétro-ingéniéré.
